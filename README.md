# Smart Critical Reminder 🚨
Smart Critical Reminder is an Android productivity and safety application designed to make important reminders harder to ignore.
## 📱 Features
- ⏰ Critical task reminders
- 🔔 High-priority notifications
- 📸 Proof of Execution using camera
- 📍 Location-based reminders
- 📱 Emergency contact alert
- 📳 Vibration and notification support
- 💾 Local reminder storage
## 🛠️ Technologies Used
- Kotlin
- Android Studio
- Jetpack Compose
- Android AlarmManager
- Android Notifications
- Camera API
- SharedPreferences
- Gson
## ⚙️ How It Works
1. Create an important reminder.
2. Set the required date and time.
3. The application triggers a notification at the scheduled time.
4. The user can complete the required task and provide proof when required.
5. If the task is not completed, the configured emergency contact can be alerted.
